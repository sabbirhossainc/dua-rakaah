# Spec Delta

## Purpose

Covers the site-wide frame every page shares: the document metadata, the favicon and the outer page layout.

## ADDED Requirements

### Requirement: Site description
Every page SHALL carry a meta description that describes the app's content, in English. It SHALL NOT name the
developer.

#### Scenario: Description on the landing page
- **WHEN** a reader's browser loads `/duas`
- **THEN** the meta description describes the dua collection, and doesn't contain "Generated by"

### Requirement: Favicon served by the app
The favicon SHALL be served from this app's own origin. The app SHALL NOT load any asset from `duaruqyah.com`.

#### Scenario: Favicon origin
- **WHEN** a reader's browser loads any page
- **THEN** the favicon URL is on the app's own origin
- **AND** no request goes to `duaruqyah.com`

### Requirement: No outer page padding
The root `<html>` element SHALL NOT add padding around the page frame.

#### Scenario: Page frame at the edges
- **WHEN** a reader opens any page
- **THEN** the `<html>` element has zero padding
